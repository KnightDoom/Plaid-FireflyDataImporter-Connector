Plaid → Firefly .env generator

Build the JSON values used by .env for this connector. This is a standalone page: save it locally or open it directly from the repository with file://. It does not contact Plaid, Firefly, or any other server.

Keep this page private. Access tokens and account mappings are sensitive. The page keeps values in your browser tab and only produces text when you click Generate.

Load existing JSON

Paste raw JSON, a generated NAME=... line, or the complete generated .env block. Loaded values replace the matching editor sections.

1. Banks and accounts

The bank key must match the key used in the destination mapping.

2. Importer profiles

Paste the exported Firefly Data Importer JSON, then define the CSV columns. Every profile needs one external_id column.

3. Generate .env values

The output is one-line JSON suitable for pasting after the matching environment variable.

Diagnostics and state

Logs avoid secret values. The state export captures all current fields, including tokens and importer JSON, so treat the file as sensitive.

The generated CSV destination paths are container paths, such as /exports/bank-one. Mount the corresponding host directory into both the connector and Firefly Data Importer containers.
